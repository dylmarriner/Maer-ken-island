Where things stand

What this dashboard can honestly claim today.

  • Creating people works. Every request goes through the same spawn and validation path the engine uses, so a dashboard human and an engine human are the same thing.
  • Storage works. Each person gets a folder with their profile, traits, cognition, social, development, reproduction, memories, state, relationships and events.
  • Creation is reproducible. The seed plus the ordered creation log produces the same people again.
  • Time is not running. Nobody ages, eats, sleeps or acts yet; the live readings on a person are the values they were built with.
